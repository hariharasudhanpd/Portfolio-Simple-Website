# Portfolio-Simple-Website

A simple personal portfolio website created using HTML and CSS. This website provides a clean and minimal way to introduce myself and allow visitors to get in touch with me.

## Pages

* **Home** – Displays my basic profile and introduction.
* **Contact** – Provides a contact form where visitors can enter their name, email, and message. It also includes links to my Instagram and LinkedIn profiles.

## Technologies Used

* HTML5
* CSS3

## Features

* Simple and clean design
* Home page
* Contact form
* Social media links
* Responsive viewport setup
